# LLM Wiki

This is the repository knowledge wiki maintained with the LLM Wiki pattern
described by Andrej Karpathy: raw sources, synthesized markdown pages and an
agent schema that explains how to keep the knowledge current.

Start here:

- [Agent instructions](AGENTS.md)
- [Wiki index](wiki/index.md)
- [Karpathy LLM Wiki source note](sources/karpathy-llm-wiki.md)
- [Maintenance log](logs/maintenance.md)

The wiki is intentionally plain markdown. There is no vector database, build
step or runtime dependency.
